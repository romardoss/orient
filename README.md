# Orient — символи спортивних карт (ISOM / ISSprOM / IOF) і генератор карт

Бібліотека умовних знаків для карт спортивного орієнтування у вигляді SVG/PNG-ассетів,
SVG-рендерер символів за їх офіційними геометричними визначеннями та процедурний генератор
лісових карт за ISOM 2017-2 з автоматичною постановкою дистанції та IOF-легендою КП.

## Швидкий старт

```bash
npm install
npm run assets   # зібрати бібліотеку символів у assets/ (~7 с)
npm run dev      # гра (index.html — головна сторінка), генератор (generator.html), каталог символів (catalog.html)
npm run game     # відкрити гру · npm run generator — відкрити генератор карт
npm test         # 32 тести (парсер, геометрія, рендер усіх символів, генератор, PDF)
npm run map -- --preset hilly --seed 42 --out out/hilly-42   # карта з командного рядка (SVG + PNG + JSON)
```

`npm run build` — статична збірка в `dist/` (разом із бібліотекою символів). Головна сторінка збірки — гра
(`dist/index.html`, див. `game/SPEC.md`); `dist/` можна викласти на будь-який статичний хостинг як є.

## Що є в `assets/`

| Набір | Символів | Джерело | Ліцензія |
|---|---|---|---|
| `isom-2017-2/` — ліс, базовий масштаб 1:15 000 | 190 | OpenOrienteering Mapper | GPL-3.0 |
| `issprom-2019-2/` — спринт, 1:4 000 | 184 | OpenOrienteering Mapper | GPL-3.0 |
| `course-design/` — курсові символи та клітинки легенд | 209 | OpenOrienteering Mapper | GPL-3.0 |
| `control-descriptions/` — IOF-легенди КП (колонки A, C–H, інструкційні рядки W–Z, зокрема «Map flip» 2024) | 186 | Purple Pen | BSD-подібна |

У кожному наборі:

- `svg/<код>.svg` — іконка 64 px, вписана в квадрат;
- `svg-true-size/<код>.svg` — той самий малюнок з `width/height` у мм (реальний друкований розмір у базовому масштабі);
- `png/<код>.png` — растр 128 px;
- `sprite.svg` — усі іконки як `<symbol id="<набір>-<код>">`;
- `manifest.json` — код, назва, тип, офіційний опис символу, шляхи до файлів, кольори;
- `symbols.json` — нормалізовані визначення (геометрія, пунктири, візерунки, кольори) для рендерера;
- `preview.png` — контактний аркуш усього набору.

Легенди КП мають назви 23 мовами (`manifest.json → names`), українського перекладу у джерелі немає.

Використання спрайта:

```html
<svg width="48" height="48"><use href="isom-2017-2/sprite.svg#isom-2017-2-204"/></svg>
```

## Як це працює

Символи не перемальовані вручну: `src/symbols/parse-xmap.ts` читає XML-визначення наборів
OpenOrienteering Mapper (`vendor/`), а `src/symbols/render.ts` будує з них SVG:

- точкові символи з елементами (лінії, площі, кола), обертання;
- лінійні — пунктир, підігнаний під довжину лінії (як у Mapper), бергштрихи/зубці (mid symbols),
  символи на початку/кінці, бордюри (подвійні лінії доріг);
- площинні — заливка + лінійні та точкові візерунки (`<pattern>`);
- комбіновані символи та текст;
- шари за пріоритетом кольорів, як у друці плашковими фарбами (чорний над коричневим над жовтим).

Кольори за замовчуванням — модель друкарських фарб CMYK (`src/symbols/colors.ts`): виглядає як
надрукована карта, а не неонові RGB-значення Mapper. Значення Mapper доступні як `mapperRgb`
і перемикач «Кольори» в генераторі.

## Генератор карт (`src/generator/`)

1. **Рельєф** — фрактальний шум із доменним викривленням і гребенями; заповнення западин
   (priority-flood) і стік D8 → струмки трьох класів, озера в низинах, ставки в глибоких западинах, болота
   за вологістю.
2. **Горизонталі** — marching squares з орієнтацією «вище ліворуч», тож бергштрихи в западинах,
   підписи висот («верх тексту — вгору по схилу») і зубці скель автоматично дивляться правильно;
   основні, потовщені та допоміжні (лише на пологих ділянках).
   Бергштрихи (101.1 / 103.1) — у западинах, у вершинах видолинків, на пологих ділянках і біля краю карти,
   з мінімальною відстанню між ними, щоб не злипалися на сусідніх горизонталях.
3. **Рослинність** — відкриті ділянки, три ступені прохідності зеленого, підлісок.
4. **Скелі** — кам'янисті ділянки трьох ступенів, голі скелі, кам'яні поля, скелі вздовж горизонталей
   на крутих скелястих схилах, валуни, групи валунів, кам'янисті ями.
5. **Дрібні форми** — горбики, видовжені горбики, западинки, ями, земляні вали, яри.
6. **Дороги та стежки** — A* за вартістю схилу/рослинності/води з повторним використанням мережі
   (утворюються розвилки), містки через струмки, будівлі й руїни, огорожі, ЛЕП, вежа на вершині.
7. **Дистанція** — старт на розвилці, КП на реальних об'єктах карти з різноманітністю типів,
   без перетину етапів, без проходження ліній через інші кола, мінімум 60 м між КП (правило IOF),
   коди 31–99 без «перевертнів» (66, 68, 86, 89, 98…), фініш; довжина і набір висоти.
8. **Додатковий курсовий друк** — пункт видачі карт (702) з маркованим шляхом до старту (707), заборонені
   ділянки й межі (708, 709), заборонений шлях (711), переходи (710), медпункт (712) і пункт води (713).
   Точкові знаки на карті малюються в 1,3 раза більшими за лінії (`POINT_BOOST` у `params.ts`).
9. **Легенда КП** — справжня IOF-сітка (колонки A–H), символи Purple Pen, розміри в колонці F,
   «розвилка стежок» як D=стежка, E=стежка, F=розвилка (специфікація IOF 2018/2024).

Однакові параметри + seed → ідентична карта (тест це перевіряє); стан зберігається в URL.

**Пакет карт (PDF)** — у правій панелі: задаєте кількість і якість (150/200/300 dpi), кожна сторінка — нова
карта з випадковим seed і випадковою місцевістю (формат, масштаб і дистанція — з форми). Карти генеруються
паралельно у воркерах, PDF збирається в браузері без залежностей (`src/app/pdf.ts`); seed кожної карти
виводиться в консоль браузера.

## Обмеження та що можна додати далі

- Генератор робить лише лісові карти ISOM; набір ISSprOM уже є, але спринт-генератора (міська забудова) немає.
- Площинні візерунки не обертаються разом з об'єктом; «загострені» кінці ліній малюються пласкими.
- Українських назв символів немає (у джерелах — англійською, легенди КП — 23 мовами).
