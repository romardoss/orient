# Orient — специфікація гри

2D-гра зі спортивного орієнтування з видом зверху та піксельною графікою. Кожен запуск — нова
процедурно згенерована місцевість. Праворуч — справжня спортивна карта ISOM 2017-2 з дистанцією,
ліворуч — світ, побудований з тієї самої карти. Ваше положення на карті **не показується**:
треба орієнтуватися за картою, рельєфом, об'єктами й компасом.

## 1. Запуск

```bash
npm install
npm run assets             # один раз: бібліотека символів ISOM (потрібна для друку карти)
npm run game               # vite dev → http://localhost:5173/ (гра — головна сторінка)
npm run generator          # генератор карт локально → http://localhost:5173/generator.html
node game/tools/make-sprites.mjs   # перегенерувати піксельні спрайти (необов'язково)
```

**Хостинг.** `npm run build` → `dist/` — повністю статичний сайт (відносні шляхи, `base: "./"`):
`dist/index.html` — гра, `generator.html` — генератор, `catalog.html` — каталог символів. Гра
генерує карти прямо в браузері (Web Worker) і бере з бібліотеки лише
`isom-2017-2/symbols.json` та `control-descriptions/symbols.json`. Викладіть увесь `dist/` у корінь
або підкаталог будь-якого статичного хостингу (GitHub Pages, Netlify, nginx) — сервер не потрібен.

Параметри URL: `?seed=123` — конкретна карта (усі параметри місцевості виводяться із сиду),
`?preset=hilly|lakes|rolling|flat|farmland|mixed|river` — пресет місцевості замість випадкової.

## 2. Екран

| Зона | Вміст |
|---|---|
| Ліва частина (8:9, на всю висоту) | Ігровий вид зверху, орієнтований за напрямком руху («heading-up»): гравець завжди дивиться вгору, світ обертається навколо нього. HUD: час, наступна ціль, штрафи, повідомлення, компас у руці. |
| Права частина (решта ширини) | Згенерована карта 1:10 000 (200×200 мм, ≈1,9×1,9 км) із дистанцією, легендою КП і масштабом. Колесо — масштаб, перетягування — зсув, `+`/`−`, `F` — уся карта. |

## 3. Керування

| Клавіша | Дія |
|---|---|
| `W` / `↑` | Вперед |
| `S` / `↓` | Назад (45 % швидкості) |
| `←` / `→` | Поворот ліворуч / праворуч (до ≈60 °/с, з плавним розгоном) |
| `A` / `D` | Стрибок убік ліворуч / праворуч на 1,3 м — обійти перешкоду. Одне натискання = один стрибок; утримання не діє, між стрибками ≥0,55 с |
| `Пробіл` | Біг вперед (другий спосіб керування) |
| Перетягування мишею по ігровому виду | Поворот (≈0,26° на піксель, без обмеження швидкості) |
| `Q` | Покласти компас на карту / прибрати (зняти азимут, див. §6) |
| `C` | Дістати / сховати компас у руці (налаштований на знятий азимут) |
| `M` (утримувати) | Підглянути своє положення на карті: +30 с штрафу за кожне натискання |
| `Enter` / `Пробіл` / `W` | Старт |
| `R` | Почати заново на тій самій карті |
| `N` | Нова випадкова карта |

## 4. Правила

1. Гравець з'являється на старті (фіолетовий трикутник) з випадковим напрямком.
2. КП (біло-помаранчеві призми з табличкою коду) треба відмітити **по порядку**: підійти ближче
   ніж на 2,5 м. Якщо підійти до чужого КП, гра скаже його код і що він не той.
3. Після останнього КП — фініш (картатий прапорець, радіус 3 м).
4. Результат: час + штраф за підглядання, пробіг (і довжина по прямій), час із компасом
   у руці, проміжні часи. Після фінішу на карті з'являється пройдений маршрут.

## 5. Рух

- Танкове керування: поворот на місці, рух вперед/назад; розгін і гальмування 13,5 м/с².
  Поворот із клавіатури плавно набирає швидкість (5 рад/с²) до 1,05 рад/с; поворот мишею — миттєвий.
- Два способи керування: `W`/`S` + `A`/`D` (або стрілки) **або** `Пробіл` (біг) + перетягування мишею.
- Базова швидкість — 9 м/с (біг відкритою місцевістю, крок ≈1,3 м). Множники:
  - **ґрунт**: дорога 1,45, мощене 1,4, ґрунтівка 1,38, стежка / міст 1,3, просіка 1,15, ліс 0,85,
    каміння 0,72, болото 0,7, струмок 0,5, мілководдя 0,4…;
  - **зелень** (ISOM 406 / 408 / 410): 0,8 / 0,62 / 0,45, плюс кущі-перешкоди (3,5 / 8 / 16 % клітинок);
  - **схил** (з поля висот генератора): вгору до ×0,45, вниз до ×1,12;
  - **компас у руці**: ×0,45.
- **Неідеальна пряма.** Поки гравець рухається, на нього діють два випадкові процеси
  Орнштейна–Уленбека:
  - дрейф кутової швидкості курсу (σ ≈ 0,015 рад/с, τ = 3,5 с) — гравець повільно звертає,
    навіть коли не тисне `A`/`D`;
  - бічне ковзання напрямку руху відносно напрямку погляду (σ ≈ 1,3°, τ = 6 с) — гравець
    трохи йде боком.
  Тому довгий азимут без компаса й орієнтирів «з'їжджає».
- **Стрибок убік** (`A`/`D`): 0,28 с у повітрі, плавне зміщення на 1,3 м перпендикулярно до
  напрямку погляду; колізії діють і в стрибку (крізь дерево не перестрибнеш, але можна оминути).
  Під час стрибка гравець трохи збільшується, а під ним лишається тінь; приземлення смикає стрілку компаса.
- **Колізії:** гравець — коло радіусом 0,32 м; тверді клітинки 1×1 м. Під час зіткнення рух
  ковзає вздовж перешкоди.

## 6. Спортивний компас і азимут

Компас — планшетний (спортивний): прозора основа зі стрілкою напрямку руху й лінійкою, лімб
(колесо) з градусами, орієнтирною стрілкою та орієнтирними лініями, магнітна стрілка.

**Зняти азимут на карті (`Q`).** Компас з'являється в центрі панелі карти (векторний, напівпрозорий):
1. тягніть основу, щоб покласти її край / стрілку напрямку вздовж етапу (від себе до КП);
2. оранжева ручка на передньому кінці основи повертає компас навколо лімба (колесо миші над
   основою — по 1°, з `Shift` — по 5°);
3. крутіть лімб (тягніть його або колесо миші над ним), доки орієнтирні лінії не стануть
   паралельні лініям магнітної півночі карти, а «N» — догори;
4. навпроти індексу читається азимут (фіолетова підпис «NN°»). На карті стрілка компаса завжди
   дивиться вгору (карта орієнтована на північ).

Математика: основа повернута на кут `α` на карті, лімб — на `−β` відносно основи (β — показ
навпроти індексу). Лімб правильно зорієнтований, коли `α − β = 0`, тобто `β = α`.

**Іти за азимутом (`C`).** У полі компас тримається основою вперед (стрілка напрямку = куди
дивиться гравець), лімб повернутий на знятий `β`, магнітна стрілка показує на північ. Гравець
повертається, доки червоний кінець стрілки не ляже в орієнтирну стрілку («будиночок») — тоді
курс = `β`. Поруч підпис «азимут NN°». Азимут зберігається, доки його не змінять на карті.

**Фізика стрілки.** Затухаючий маятник: `φ'' = −k·(φ − північ) − c·φ'`, k = 22 с⁻², ζ ≈ 0,27.
Коли компас дістають, стрілка стартує під випадковим кутом 60–155° від півночі й заспокоюється
за ~2–3 с («стрілка гуляє…» → «стрілка стала»). Під час ходьби тремтить (шум ∝ швидкості),
отримує поштовх на кожен крок і приземлення після стрибка; різкий поворот теж розгойдує її.
Поки компас у руці, гравець рухається повільніше (×0,45).

Рендер: основа 40×72 і лімб 36×36 px (піксель-арт), на екрані ×3; поворот лімба й стрілки
семплюється в екранній роздільності, тож пікселі лишаються чіткими без «шуму».

## 7. Побудова світу з карти

Для гри генератор отримує менше зелені (`vegetation` ×0,6) і води (`water` ×0,7), ніж на
звичайній карті: менше хащ і боліт, більше біганини та навігації.

Карту генерує існуючий генератор проєкту (`src/generator`): рельєф → вода → дороги →
рослинність → горизонталі → скелі → дрібні форми → будівлі → дистанція. Гра запускає той самий
конвеєр у Web Worker (`game/src/worker.ts`), додатково зберігаючи поле висот, і:

1. друкує SVG-карту (`drawMap`) — праворуч;
2. растеризує всі об'єкти моделі в сітку 1 м (`game/src/world.ts`):
   - **площі** (scanline, even-odd): відкриті ділянки, сади/виноградники, болота, вода,
     кам'янисті ґрунти, будівлі, заборонені ділянки, зелень (окремий шар густоти);
   - **лінії** (штампування диском заданої ширини): яри, вали, струмки, скелі, стіни, огорожі,
     дороги/стежки/просіки, мости. Стежки прорізають огорожі (хвіртки); на огорожах і стінах
     ще й кожні 45 м — прохід 2,5 м;
   - **точки**: валуни, групи валунів, горбики, ями, колодязі, джерела, вежі, тури, примітні
     дерева, малі будівлі, руїни;
   - **розсіювання** (детермінований хеш клітинки): дерева в лісі (≈3,4 %, з мінімальною
     відстанню), кущі за густотою зелені, валуни на кам'яних полях, декор (папороть, очерет,
     камінці); сади — дерева сіткою 7 м, виноградники — ряди кущів;
   - **відмивка рельєфу** з градієнта поля висот (світло з північного заходу) — схили видно
     в ігровому світі, і їх можна зіставити з горизонталями карти;
   - навколо старту, КП і фінішу (2,5 м) випадкових перешкод немає, а старт/фініш завжди вільні.
3. Непрохідні: глибока вода, непрохідне болото, будівлі, заборонені ділянки, скелі, стіни,
   огорожі, дерева (стовбур), кущі, валуни, вежі, колодязі, тури, годівниці.

## 8. Графіка

- Сцена малюється в буфер 320×360 (8 px = 1 м), повернутий за курсом, і масштабується ×2
  без згладжування — увесь кадр, зокрема обертання, зберігає піксельний вигляд.
- Ґрунт і низькі об'єкти запікаються в кешовані чанки 32×32 м (LRU, до 90 штук) з
  перекриттям в 1 клітинку, щоб під час обертання не було швів.
- Крони дерев малюються поверх гравця; поруч із ним — напівпрозорі.
- Маркери (старт, КП, фініш) завжди стоять вертикально на екрані; над КП — табличка з кодом
  (видно лише в межах 80 % радіуса видимості).
- **Видимість.** Що густіший ліс, то менше видно. У колі 9 м навколо гравця рахується щільність:
  `d = 6·частка_дерев + 4·частка_кущів + 0,25·середня_зелень`, радіус видимості
  `R = 7 + 51 / (1 + 15·d)` м: відкрита місцевість ≈58 м (туману немає), звичайний ліс ≈18–22 м,
  непролазні хащі ≈8–9 м. Радіус плавно підлаштовується (≈0,7 с), а за ним ліс темніє: від 0,6·R
  до 1,2·R затемнення наростає до 93 % у 6 ступенів із дизерингом Баєра 4×4, щоб край туману
  зберігав піксельний вигляд.

## 9. Звук

Квадратна хвиля через WebAudio: тихі кроки, подвійний сигнал на КП, низький — на чужому КП,
мелодія на фініші.

## 10. Структура

```
index.html           — гра (головна сторінка; розмітка двох панелей)
generator.html       — генератор карт (сторонній інструмент)
game/
  SPEC.md            — цей документ
  assets/            — піксельні PNG
  tools/make-sprites.mjs
  src/
    main.ts          — параметри, цикл гри, правила, HUD, ввід
    worker.ts        — генерація карти, друк SVG, побудова світу
    world.ts         — растеризація ISOM → ґрунт/зелень/об'єкти/колізії/відмивка
    player.ts        — рух, дрейф, швидкість за місцевістю, колізії
    compass.ts       — фізика стрілки, піксельний спортивний компас у руці
    mapcompass.ts    — компас на карті: перетягування, поворот основи й лімба, азимут
    view.ts          — рендер ігрового виду (чанки, крони, маркери)
    mapview.ts       — панель карти (растр SVG, масштаб, зсув, маршрут)
    sprites.ts       — завантаження PNG
```

## 11. Можливі розширення

- Обертання карти в руці (орієнтування карти за компасом).
- Магнітне схилення (зараз магнітна північ = північ карти).
- Таблиця рекордів за сидом.
- Інші дистанції (кількість КП / довжина) з меню.
